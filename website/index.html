CLI 安装与使用

开发者首选 —— 一条命令装好，同时获得终端 TUI + 本地 server + Web UI

📦 npm 全局安装（推荐）

安装后即可使用 dscode 命令。

npm install -g @deepseekcode/cli

# 验证
dscode --version

要求 Node.js ≥ 18。安装后同时提供 dscode 与 deepseekcode 两个命令。

⚡ Bun 全局安装

已在用 Bun？用 Bun 安装同样简单。

bun add -g @deepseekcode/cli

# 验证
dscode --version

要求 Bun 已安装。

🔽 离线 / 内网安装

从 npm Registry 下载 tarball 后离线安装。

curl -fLO https://registry.npmjs.org/@deepseekcode/cli/-/cli-1.0.3.tgz
npm install -g ./cli-1.0.3.tgz

适用于无法直连 npm 镜像的内网 / 离线环境；Windows 可用 Invoke-WebRequest 下载该文件。

🚀 快速开始

dscode                     # 本地启动（内置 server + TUI），首次运行引导配置
dscode start               # 同 dscode，显式启动本地核心
dscode run --backend URL   # 连接已运行的 server
dscode exec "修复 README 里的拼写错误"   # 非交互单次执行（JSONL 输出）
dscode codeview            # AI 代码审查：找 bug + 未接线的功能
dscode --resume            # 恢复上次会话
dscode --help              # 查看全部命令与参数

⌨️ TUI 内常用斜杠命令

/plan      切换规划模式     /mode act|plan|goal   直接切换模式
/auto      切换自动批准     /model <模型名>       切换 AI 模型
/tasks     任务看板         /mcp <action>        管理 MCP 服务
/theme     切换终端主题     /clear                清空对话
配置提示：CLI 与桌面版共用 ~/.agent/ 配置目录（Windows 为 %USERPROFILE%\.agent）。直接编辑 config.yaml 填写 baseUrl / apiKey / model 即可接入模型服务；会话与日志默认保存在 ~/.agent/logs/。

下载安装

安装包由 GitHub Actions 自动构建（Tauri 2），当前版本 v1.0.0

⚠ 私有仓库提示：本仓库为私有仓库，通过 GitHub 下载安装包需要登录 GitHub 并拥有该仓库的访问权限。 如需面向外部用户分发，请将安装包同步到自己的下载服务器/CDN，然后修改页面顶部 CONFIG.downloadBaseUrl， 下载按钮将自动切换到你的服务器地址（文件名保持不变即可）。
校验与安全：正式安装包未配置代码签名证书时，Windows 可能提示 SmartScreen（点“更多信息”→“仍要运行”）， macOS 首次打开需右键 → 打开。建议在 GitHub Release 页核对 SHA256 校验和（发布后从 Actions 产物中获取）。

数据与隐私

桌面版默认行为一览

服务仅监听本机server 只绑定 127.0.0.1，局域网不可达，外部无法调用你的文件与命令工具。
数据保存在本地配置、会话、日志存放在系统用户目录（Windows: %APPDATA%\deepseekcode；macOS/Linux: ~/.config/deepseekcode）。
工作区自选首次启动选择工作目录，AI 的所有文件操作都在该工作区内进行。
LLM 调用你可控模型、API 地址、密钥均在本地配置；你的代码只发送给所配置的模型服务商。

常见问题

安装与使用中可能遇到的问题

第一次启动为什么要选择工作目录？
工作目录是 AI 智能体进行文件读写、命令执行的根目录。选择你想要让助手工作的项目文件夹即可；也可以设置环境变量 DSC_WORKSPACE 跳过选择。
Windows 提示 SmartScreen / macOS 提示“无法验证开发者”？
当前安装包未做代码签名。Windows 请点击“更多信息”→“仍要运行”；macOS 请在 Dock 或访达中右键应用 →“打开”。后续配置签名证书后即可消除提示。
如何更新到新版本？
下载新版本安装包覆盖安装即可（配置文件与会话历史会保留在用户目录）。也可以直接关注仓库 Release 页的 desktop-v* 标签。
AI 模型如何配置？
应用内支持 OpenAI 兼容接口：配置 baseUrl / apiKey / model 即可，支持 openai、ollama、lmstudio 等 Provider。
端口冲突怎么办？
桌面版每次启动会自动挑选空闲端口（仅 127.0.0.1），不会与你手动启动的服务冲突。启动失败时日志位于 %APPDATA%\deepseekcode\logs\。
CLI 和桌面版有什么区别？
核心引擎完全相同（本地 server + 同一套 Agent 运行时）。桌面版是 Tauri 2 原生窗口 + Web UI；CLI 是终端 TUI（dscode），支持非交互执行与脚本化。二者共用 ~/.agent/ 配置与会话。
CLI 需要什么运行环境？
只需 Node.js ≥ 18 或 Bun。全局安装：npm install -g @deepseekcode/cli 或 bun add -g @deepseekcode/cli。Windows / macOS / Linux 均支持。
